# Quiz Application with Timer

## About the Project

This project is developed as part of Task 4 of the CodSoft Java Development Internship. It is a console-based quiz application that asks multiple-choice questions and checks the user's answers.

## Features

* Displays multiple-choice questions with four options.
* Provides a time limit of 10 seconds for each question.
* Checks whether the selected answer is correct.
* Displays the correct answer for incorrect responses.
* Calculates the final score and percentage.

## Technologies Used

* Java
* Scanner class
* Arrays
* Loops
* Conditional statements
* System time calculation

## How to Run

1. Install JDK on your system.

2. Download or clone this repository.

3. Open the project folder in the terminal.

4. Compile the Java program:

   javac QuizApplication.java

5. Run the program:

   java QuizApplication

## How to Play

1. Run the program.
2. Read each question and its options.
3. Enter A, B, C, or D as your answer.
4. Try to answer within 10 seconds.
5. Check your final score and percentage after completing the quiz.

## Learning Outcomes

Through this project, I practiced Java arrays, loops, conditional statements, user input handling, and time calculation.
